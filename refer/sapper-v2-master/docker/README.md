# Container-era design references

This directory preserves the upstream commander's doctrine, architecture,
environment documentation, and runtime scripts for study. The scripts assume
the original container filesystem and toolchain; they are not a standalone
local installation.

This reference copy no longer includes Dockerfiles, image build/export scripts,
the local container launcher, or `nuclei.zip`. Install the local fact-intent CLI
with `bash install.sh` from the sapper project root; see [the quick start](../README.md#6-quick-start).
